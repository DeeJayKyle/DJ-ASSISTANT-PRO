DJ Assistant 2.0.3

**Long mixes in the Studio, and a faster Library.**

**Stems for long songs and DJ mixes**
- **Fast stems split long files in 30-second parts**, so memory stays close to the size of the stems themselves. A 30-minute mix now splits in under a minute using 4.6 GB (it took almost three minutes and 6.8 GB before). A 5-minute song takes about 14 seconds, twice as fast as before.
- **No more running out of memory.** Before splitting, DJ Assistant checks the memory your PC has free. If a song is too long to split at the moment, it says how much is needed instead of crashing. Closing other apps usually helps.

**A faster Library**
- **Scrolling a big library is smooth.** With 50,000 tracks, each new screenful used to take up to half a second to load; now it takes a millisecond or two.
- Search uses every word you type (it used to stop after 12).

**Ogg Vorbis and Opus**
- Windows decodes these once Microsoft's free **Web Media Extensions** are installed (Microsoft Store). Most PCs have them already. If yours doesn't, DJ Assistant now says so and names what to install, instead of showing an error code.

**Please note:** the installer is signed for automatic updates, but not code-signed, so Windows SmartScreen may show an "unknown publisher" warning.
