DJ Assistant 2.1.0

**Beatgrids, prepared stems and new DJ Decks.**

- **Whole-file beatgrids.** Analysis now finds every beat in a track: one grid for a steady track, a marker at each tempo change for live or edited ones, plus the first beat and bar 1. Your library is re-analysed once after updating so every track gets one. BPM and key results are unchanged.
- **BPM range** (Settings → Library): automatic, or 58–115, 68–135, 78–155, 88–175, so half- and double-time readings land where you want them.
- **Better keys on off-tune tracks.** Music tuned well away from A = 440 Hz (pitched vinyl rips, older recordings) is read on its own tuning.
- **Serato's own grid and BPM.** If Serato has analysed a track, DJ Assistant reads Serato's beatgrid and BPM from the file and uses that grid. Your files are only read, never changed.
- **rekordbox exports carry the beatgrid**, so tracks arrive in rekordbox already gridded.
- **Prepared stems.** A song is split once and its stems are kept on this computer (never beside your music), so it loads instantly next time. Stems → **Prepare stems** splits a whole crate ahead of a gig. Settings → Studio sets the space they may use, or removes them all.
- **New DJ Decks.** Both waveforms scroll side by side with beat and bar lines, cues and loops; each deck has hot cue, loop and stem pads; the mixer sits between the decks; load songs from the library underneath.

**Please note:** the installer is signed for automatic updates, but not code-signed, so Windows SmartScreen may show an "unknown publisher" warning.
